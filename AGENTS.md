## Agent skills

### Issue tracker

Issues are tracked as local Markdown files under `.scratch/<feature>/`, which is git-ignored and
not part of the published repository. See `docs/agents/issue-tracker.md` for the convention.
Durable outcomes belong in `docs/`, an ADR, or `CHANGELOG.md` rather than only in a ticket.

### Triage labels

Triage states use the five default canonical labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses the single-context domain-doc layout. See `docs/agents/domain.md`.
