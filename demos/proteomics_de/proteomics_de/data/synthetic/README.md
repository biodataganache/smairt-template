# Synthetic data

Generated in-project, not obtained from an external source. These files are **outputs with a known
answer planted in them**, which is what lets the analysis measure false discovery control rather
than estimate it.

## How to regenerate

```bash
python3 experiments/01_synthetic/script_01_bh_correction.py
```

Deterministic given the seed, so a regenerated file matches the checksums above.

Generated by `experiments/01_synthetic/script_01_bh_correction.py`, and read by iterations 02 and
03 so all three test the same planted truth.

## Why the ground truth is a separate file

`synthetic_metadata.csv` holds which proteins were *actually* changed. Keeping it beside the
abundance matrix rather than inside it means an analysis can be written against the abundances alone
and scored afterwards, instead of having the answer in the same table it is meant to discover.

## What this does not establish

That the method works on real proteomics data. Planted effects here are clean: no batch effects, no
missing values in iteration 01, and noise that is Normal by construction. Iteration 03 adds
missingness and heteroscedasticity for exactly that reason.
