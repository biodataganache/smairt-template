# Historical Modernization Proposal

> **Status: superseded historical record.** This proposal predates the V0.1
> installed CLI and is not an implementation plan or user guide. Its proposed
> generator options and session-transfer mechanisms were not adopted.

The proposal identified practices that were subsequently incorporated into the
canonical scaffold: individual hypothesis and analysis files, numbered or
track-based experiments, separate raw logs, planning documents, direct use of
project files by coding assistants, and optional HPC and publication guidance.

The current supported workflow is defined by `README.md`, `QUICKSTART.md`, and
the files generated by the installed `smairt` CLI:

```text
question/background -> hypothesis -> phase experiment -> results/logs
  -> analysis/decision -> study report
```

Paper support is an additive overlay enabled with `--paper` or
`smairt paper enable`; it does not replace the phase-based experiment and audit
trail. HPC support supplies editable guidance only and does not submit jobs.

The original proposal is intentionally not reproduced because its command and
template suggestions no longer describe the shipped product. Repository history
remains the source for reviewing that design discussion.
