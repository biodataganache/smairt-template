# Archived Original Cookiecutter Template

This directory is an unmodified recovery of the Cookiecutter template from
commit `78f22af`. It is unsupported, reference-only historical content. Use the
installed `smairt` CLI for project generation.

Known defects include Git initialization before later hook cleanup (leaving a
dirty generated repository) and stale browser/IDE workflow cleanup behavior.
These defects are intentionally preserved.
