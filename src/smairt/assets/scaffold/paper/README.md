# Paper Workspace

Paper support is an optional publication overlay on the same scientific audit trail used by
every SMAIRT project. It does not create a separate project mode.

- Develop manuscript structure in `outline.md`.
- Connect publication interpretation to core analyses in `analysis/`.
- Keep versioned drafts in `drafts/`.
- Record reviewer comments and responses in `reviewer_feedback/`.
- Map every claim and figure to evidence in root `FINAL_MANIFEST.md`.

Raw logs, experiments, hypotheses, and core analyses remain authoritative. If Paper support
is deactivated, these files remain in place as researcher-owned history.
