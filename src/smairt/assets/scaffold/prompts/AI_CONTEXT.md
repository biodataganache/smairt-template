# SMAIRT AI Context

This project follows a hypothesis-driven research workflow. Keep scientific
judgment with the researcher. Before complex work, create a plan. For each
iteration, maintain a traceable chain from hypothesis to experiment script to
run log to analysis. Record raw output in `results/logs/` first; summarize it
in `analysis/` after inspection.

Do not invent results, overwrite researcher-authored material, or treat this
workspace as a substitute for scientific review.
