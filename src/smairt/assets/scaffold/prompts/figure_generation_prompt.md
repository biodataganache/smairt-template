# Publication Figure Guidance

Before creating or revising a figure:

1. Read the source hypothesis, script, data provenance, raw log, and analysis.
2. State the claim the figure supports and the boundaries it must show.
3. Preserve source code and parameters needed to regenerate it.
4. Use readable labels, units, uncertainty, legends, and accessible colors.
5. Avoid transformations or selections not documented in analysis.
6. Save appropriate editable/vector and display formats.
7. Update `FINAL_MANIFEST.md` with source paths and generation details.

Never infer or fabricate values to complete a visual narrative.
