# Paper Iteration Review

Review the current manuscript iteration without moving, copying, or deleting scientific
evidence.

```text
Read the current draft, outline, FINAL_MANIFEST.md, study report, and linked core analyses.
For each claim and figure, verify source evidence, uncertainty, boundary conditions, and
limitations. Identify unsupported language, missing citations, inconsistent terminology,
and stale manifest links. Propose a bounded revision plan and preserve prior drafts.
```

Record reviewer-style findings separately from the revised draft so decisions remain auditable.
