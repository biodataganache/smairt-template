# Literature Search Records

Create one Markdown record per coherent search session using
`YYYYMMDD_short_topic.md`. Record the research sub-question, providers, exact
queries, filters, date, candidate results, and researcher decisions.

Each record should contain a candidate table with:

| Candidate | Identifier or URL | Provider | Why it may matter | Decision | Reason |
|---|---|---|---|---|---|

Use `APPROVE`, `REJECT`, or `NEEDS REVIEW`. Do not create a source folder until
the researcher explicitly approves that candidate.
