# Selected Sources

Create one folder here for each researcher-approved source. Copy
`../REFERENCE_TEMPLATE.md` into the folder as `reference.md`, then create
`paper/`, `supplemental/`, and `data/` subdirectories.

Zoo must not create folders for unreviewed search results. Before using a source
to support a claim, read its `reference.md` and verify the claim against the
source file or canonical record.
